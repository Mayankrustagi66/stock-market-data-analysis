# Stock Prediction Project

A Machine Learning based Stock Price Prediction project built using Python and Linear Regression.

## Features
- Stock price prediction using historical data
- Data preprocessing with Pandas
- Linear Regression model using Scikit-Learn
- Graph visualization with Matplotlib
- Model evaluation using Mean Squared Error

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

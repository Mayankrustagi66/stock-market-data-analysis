# Stock Market Data Analysis & Prediction

A data analysis project focused on analyzing historical stock market trends and predicting closing prices using Python.

## Project Overview
This project uses historical stock market data to perform:
- Data preprocessing and cleaning
- Exploratory data analysis
- Trend visualization
- Predictive analysis using regression

The project demonstrates practical skills in data handling, analysis, visualization, and model evaluation.

## Key Features
- Historical stock data analysis
- Data preprocessing using Pandas
- Trend prediction using Linear Regression
- Data visualization with Matplotlib
- Performance evaluation using Mean Squared Error

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Dataset
The dataset contains:
- Open Price
- High Price
- Low Price
- Closing Price
- Trading Volume
- Date Information

## Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Feature Selection
4. Data Visualization
5. Predictive Analysis
6. Performance Evaluation
